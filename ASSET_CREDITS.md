# COSMOS asset provenance

Earth: Blue Marble Next Generation, NASA Earth Observatory, reproduced from the locally installed basemap_data `bmng.jpg` image (5400×2700) and prepared at 4096×2048 for this project. The moving Earth cloud map is an original procedural visualization and is not an observed cloud field.

Mars, Jupiter, Saturn, Neptune, Mercury, and Venus: enhanced versions of texture images supplied in the user's original 3Dplanet.zip. Source archival data and usage conditions should be checked on https://space.jpl.nasa.gov/tmaps/ before publication.

Uranus: entirely procedural atmosphere map replacing a featureless input texture; artistic representation only.

Backgrounds: compressed versions of Gemini-generated images from the user's original ZIP.

This project is an independent educational visualization, not NASA-affiliated. Sizes, positions, cloud motion, illumination, and transition timings are not physically simulated.

## Planet and moon refinements (2026 COSMOS version)
- The Moon, Europa, Titan and Enceladus visualizations use **newly generated 3072 × 1536 artistic textures** created for this website. Craters, fractures and haze are interpretations, **not photogrammetry or scientific maps**.
- Procedural normal maps on Mercury, Venus, and Mars and the three solid/icy moon globes add light-responsive surface texture. These relief maps are inferred from source brightness / generated patterns, not measured elevation data.
- Mercury's historical surface map contained missing/white data. The high-contrast missing regions were visually inpainted for presentation; no unobserved terrain is implied to be authentic.
- `assets/audio/cosmos-ambient.mp3` is a loop-ready adaptation of the user-provided `COSMOS.mp3` soundtrack (approximately 3 minutes). A 10-second overlap was used to create an approximately 150-second loop; playback remains opt-in. Confirm the track's licensing/ownership before public distribution.
- Original planetary map attribution remains unchanged. NASA planetary resources: https://maps.jpl.nasa.gov/tmaps/ .

## Discovery Suite extras

- `public/assets/effects/earth-lights.webp`: programmatically drawn artistic city-light clusters based on approximate city coordinates. Not satellite-observed night lights.
- Hotspot names, summaries, and coordinates: educational summaries with NASA science links inside the interface; approximate marker placement.
- No additional proprietary third-party media was copied for these modules.

## Deep Exploration Edition
- Interior cross sections, procedural surface landscapes and exoplanet renders: created programmatically as educational artist concepts; no actual photographed sub-surface terrain or exoplanet surfaces are claimed.

- Photo Mode uses the planet textures already credited elsewhere in this document.
- The original COSMOS soundtrack remains unmodified in the asset bundle.
